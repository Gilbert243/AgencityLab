# AgencityLab Documentation

This folder contains the source files for the AgencityLab documentation.

Main sections:

- `theory/` — theoretical foundations, equations, principles, and interpretation;
- `api/` — stable public API reference;
- `tutorials/` — practical and reproducible workflows;
- `examples/` — worked examples and visualization gallery;
- `references/` — bibliography and glossary;
- `scientific_validation.md` — deterministic validation scope and scientific limits;
- `agencity_analysis.md` — diagnostics kept separate from canonical computation;
- `multiscale_extensions.md` — multiscale, window, discrete, and multivariate constructions;
- `scientific_ux.md` — researcher-facing workflow, reports, figures, and exports;
- `engineering_performance.md` — v0.8 profiling, benchmarks, memory, packaging, and backend status.

Build the documentation with the optional documentation dependencies. Benchmark observations and diagnostic thresholds are not canonical equations or empirical validation claims.
