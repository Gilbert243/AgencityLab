# Agencity theory notes in the package

This directory contains working theory-oriented notes that accompany the Python package. It is **not** the authoritative source of the Agencity theory, and short or incomplete files here must not be treated as normative equations merely because they are shipped with the code.

For the repository's current theory-to-code contract, use [`../../docs/theory_mapping.md`](../../docs/theory_mapping.md). That mapping records the selected current theory target, the implementation paths, and known discrepancies that are intentionally deferred to scientific reconciliation.

When these notes are expanded, each statement should be labelled or written so that readers can distinguish canonical definitions, experimental extensions, heuristics, diagnostics, and legacy formulations.
